data-analyst-agent

A LangGraph agent that answers questions about CSV and Excel files by writing Python, running it in a separate process with a timeout, and answering from the printed output. A scripted demo mode runs without an API key.

Problem

The first version of this project ran model-written code with exec() inside the Streamlit process. The code shared one module-level namespace across all browser sessions, inherited every environment variable of the app including the API keys, and had no time limit, so a while True loop never returned. Its docstrings described a path restriction and a timeout that the code did not implement.

The replacement and its tests: src/data_analyst_agent/executor.py, tests/test_executor.py (16 tests).

How it works

A two-node LangGraph loop calls the model and the run_python tool until the model answers without a tool call. Each tool call runs in a new Python process with a temporary working directory, an environment of seven allowlisted variables, a cap on captured output and a wall-clock timeout that kills the whole process group. Files the code saves to outputs/ are shown in the chat.

flowchart TB
  user["Question"] --> agent["agent node: chat model"]
  agent -- "tool call" --> tools["tools node: run_python"]
  tools --> executor["new Python process, temporary directory"]
  executor -- "output, exit code, saved files" --> tools
  tools --> agent
  agent -- "answer" --> user

Measured results

A new process per call means the interpreter start and the imports are paid on every call. Median wall time of run_python, 20 runs per case after 2 warm-up runs, one Linux x86_64 machine with 6 logical CPUs, Python 3.11.13, revision 4a93e33. Run it

  1. git clone https://github.com/darblinko/data-analyst-agent
cd data-analyst-agent
  2. uv sync
uv run pytest -q
  3. DEMO_MODE=1 ./run.sh

Open http://localhost:8501 and pick a demo question. For your own questions, copy .env.example to .env, set OPENAI_API_KEY or ANTHROPIC_API_KEY and run ./run.sh.

Limitations

  • Process isolation is not a security sandbox. The child runs as the app's user, can read that user's files, including a .env file, and has network access. Untrusted prompts or files need a container or VM.
  • Saved HTML charts render in a Streamlit component iframe with allow-scripts and allow-same-origin.
  • Variables do not persist between code runs; the model reloads the data in every call.
  • The tests use a scripted replay model only. Behavior with live OpenAI and Anthropic models is not tested.
  • POSIX only: the timeout uses process groups. A process that the generated code moves to a new session or process group is not killed.
